# 提交要求

存在 `structured_output` 工具时，最终结果只通过该工具提交，不在助手正文中打印 JSON 或 Markdown 代码块。只有工具不存在时，才用相同字段返回一个不带代码围栏和说明的裸 JSON 对象。

# 有修改

- `summary`：用简体中文简短概括本次局部修改
- `revisedPrompt`：完整候选提示词，保持原提示词语言
- `reasons`：用简体中文列出对话证据为何支持本次修改；不要抄写修改前后的提示词片段

# 不修改

- `summary`：用简体中文简短说明证据为何不足
- `revisedPrompt`：完整原提示词，不作任何修改
- `reasons`：空数组
